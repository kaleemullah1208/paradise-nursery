# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery — Houseplant Shopping Cart App

## Description
Paradise Nursery is a React-based e-commerce front end for an online houseplant shop. Users can browse houseplants organized by category, add them to a shopping cart, adjust quantities, remove items, and view the total cost before checkout.

## Features
- Landing page with background image, company info, and "Get Started" button
- Product listing page with houseplants grouped into 3+ categories
- Add to Cart with auto-disable after adding
- Dynamic shopping cart icon in the navbar
- Shopping cart page with quantity increase/decrease, delete, totals, and checkout

## Tech Stack
- React (Vite)
- Redux Toolkit
- React Router DOM
- CSS
